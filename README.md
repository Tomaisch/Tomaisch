## Projects

These are team projects from my Liora / DataScientest courses. Each README explains
what I worked on.

### [Weather rain prediction](https://github.com/Tomaisch/weather-rain-prediction)
An MLOps system that predicts whether it will rain tomorrow at Australian weather stations.
I built the FastAPI endpoints, the first Airflow pipeline, and the monitoring with
Prometheus, Grafana and alerts.

### [Rakuten product classification](https://github.com/Tomaisch/rakuten-product-classification)
Classifies e-commerce products into 27 categories from text and images. I built an
image model and a model that combines image and text (weighted F1 of 0.899 on the
validation set).

## Master's thesis

### Master's thesis: Dynamics of coral-associated microbial communities under acute thermal stress following long-term warming

How do microbial communities in corals shift under acute thermal stress after long-term
warming? I investigated this using 16S rRNA gene sequencing and metagenomic NGS data.

- **R packages:** DADA2, phyloseq, DESeq2
- **Other bioinformatics tools:** PICRUSt2, MMseqs, BLASTx, Kaiju
